# Acompanhamento e Aprendizado (Patrimônio Real ao Longo do Tempo) Implementation Plan

> **For agentic workers:** This plan is intended for direct/inline execution (e.g. by Codex), not `superpowers:subagent-driven-development` — follow `superpowers:executing-plans` if that skill is available, otherwise execute the tasks below in order, running each task's tests before moving to the next. Read `AGENTS.md` at the repo root first — it has the conventions this plan assumes (module structure, cross-module import rules, Docker Compose workflow, migration application, testing conventions) and isn't repeated here. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new Go module `tracking` that periodically snapshots the real Binance testnet account's total value (cash + priced positions) into a new table, expose it through `web-api`'s existing read-only API, and show it as a new "Patrimônio" tab in the dashboard, reusing the equity-curve chart already built for backtests.

**Architecture:** `tracking/cmd/tracker` is a long-running process (same shape as `market-data`'s live-collection loop and `web-api`'s own container) that polls `execution/executor.Client.FetchPortfolio` every `SNAPSHOT_INTERVAL_MINUTES` (default 15), prices each held position via the latest `1m` candle (same read-the-table-directly pattern `strategist/internal/storage.LatestPrice` already uses), and persists one `equity_snapshots` row per cycle. `web-api` gets one new read-only endpoint reading that table directly — no Go import of `tracking` needed, same pattern as its 6 existing endpoints. The frontend gets one new page reusing the existing `EquityCurveChart` component and `EquityPoint` type verbatim (the new table has the exact same shape as `backtest_equity_curve`).

**Tech Stack:** Go 1.22 (matches every sibling module except `mcp`), `github.com/jackc/pgx/v5 v5.6.0` (same version pinned everywhere else in this repo). No new frontend dependency — reuses existing React/TypeScript types and components.

**Spec:** `docs/superpowers/specs/2026-08-19-tracking-design.md`

## Global Constraints

- **`tracking` imports `execution/executor` (a public package) and, transitively through it, needs `risk-engine`'s source available too** — both need a `replace` directive AND a matching `docker-compose.yml` volume mount in `tracking`'s own `go.mod`/`docker-compose.yml`, even though `tracking`'s own code only references `risk-engine/risk`'s `ReferenceExchange` constant directly (for consistency with `strategist`'s identical `LatestPrice` call pattern) and never touches `risk.Side` itself. This mirrors exactly how `mcp`'s `go.mod` needed its own `replace execution => ../execution` in sub-project 8, even though `mcp` never imports `execution` directly — a dependency's own `replace` directives are never inherited by whatever imports it.
- **A snapshot cycle that fails partway (portfolio fetch error, or any held position's price unavailable) skips that cycle entirely and logs — it never persists a partial/inaccurate snapshot.** The next cycle tries again from scratch.
- **The loop polls once immediately at startup, then on every tick** — same pattern as `market-data/internal/scheduler.pollFundingAndOI`, so a snapshot exists right away rather than only after the first full interval elapses.
- **This module never writes to any table it doesn't own.** It only reads `candles` (via raw SQL, no Go import of `market-data`) and calls `execution/executor.Client.FetchPortfolio` (a read-only method) — it has no write access to any other module's data.
- **`web-api`'s existing 6 endpoints, `mcp`, `strategist`, `execution`, `analysis`, `risk-engine`, `simulation` are untouched.** Only `web-api` (one new file each in `internal/storage`/`internal/api`, plus a one-line addition to `server.go`'s existing `dataStore` interface and route table) and `frontend` (one new file, plus small additions to two existing files) change outside the new `tracking` module.
- **Reduced test rigor, per this repo's established policy** (see `AGENTS.md`): direct tests for `tracking`'s snapshot computation and error-skip logic (with fakes, no real Binance/DB needed for those), and for the storage round-trip (`TEST_DATABASE_URL`-gated, skips cleanly if unset). No test calls the real Binance API.

```go
import (
	"context"

	"github.com/jackc/pgx/v5/pgxpool"

type Store struct {
	pool *pgxpool.Pool
}

func New(ctx context.Context, dsn string) (*Store, error) {
	pool, err := pgxpool.New(ctx, dsn)
	if err != nil {
		return nil, err
	}
	if err := pool.Ping(ctx); err != nil {
		pool.Close()
		return nil, err
	}
	return &Store{pool: pool}, nil
}

func (s *Store) Close() {
	s.pool.Close()
}
```

```go
// tracking/internal/storage/marketdata.go
package storage

import (
	"context"
	"errors"

	"github.com/jackc/pgx/v5"
)

// LatestPrice returns the most recent closed candle's close price for
// exchange/symbol/timeframe (the market-data module's candles table,
// read here directly — no Go dependency on that module, same pattern
// strategist/internal/storage.LatestPrice already uses). found is false
// if no candle has been collected yet.
func (s *Store) LatestPrice(ctx context.Context, exchange, symbol, timeframe string) (price float64, found bool, err error) {
	err = s.pool.QueryRow(ctx, `
		SELECT close FROM candles
		WHERE exchange = $1 AND symbol = $2 AND timeframe = $3
		ORDER BY ts DESC LIMIT 1
	`, exchange, symbol, timeframe).Scan(&price)
	if errors.Is(err, pgx.ErrNoRows) {
		return 0, false, nil
	}
	if err != nil {
		return 0, false, err
	}
	return price, true, nil
}
```

```go
// tracking/internal/storage/snapshots.go
package storage

import (
	"context"
	"time"
)

// Snapshot is one persisted equity_snapshots row — a point-in-time
// measurement of the real account's total value.
type Snapshot struct {
	Timestamp      time.Time
	Cash           float64
	PositionsValue float64
	TotalEquity    float64
}

func (s *Store) SaveSnapshot(ctx context.Context, snap Snapshot) error {
	_, err := s.pool.Exec(ctx, `
		INSERT INTO equity_snapshots (ts, cash, positions_value, total_equity)
		VALUES ($1, $2, $3, $4)
	`, snap.Timestamp, snap.Cash, snap.PositionsValue, snap.TotalEquity)
	return err
}

// RecentSnapshotForTest reads back the single most recent snapshot —
// used by tests to verify SaveSnapshot persisted what was asked.
func (s *Store) RecentSnapshotForTest(ctx context.Context) (Snapshot, error) {
	var snap Snapshot
	err := s.pool.QueryRow(ctx, `
		SELECT ts, cash, positions_value, total_equity
		FROM equity_snapshots
		ORDER BY ts DESC LIMIT 1
	`).Scan(&snap.Timestamp, &snap.Cash, &snap.PositionsValue, &snap.TotalEquity)
	return snap, err
}

// DeleteSnapshotsForTest removes equity_snapshots rows at or after since
// — used by tests to clean up after themselves.
func (s *Store) DeleteSnapshotsForTest(ctx context.Context, since time.Time) error {
	_, err := s.pool.Exec(ctx, `DELETE FROM equity_snapshots WHERE ts >= $1`, since)
	return err
}
```

```go
// tracking/cmd/tracker/main.go
package main

import (
	"context"
	"fmt"
	"log"
	"os"
	"os/signal"
	"strconv"
	"syscall"
	"time"

	"risk-engine/risk"

	"execution/executor"

	"tracking/internal/storage"
)

const (
	defaultIntervalMinutes = 15
	priceTimeframe         = "1m"
)

func main() {
	if err := run(); err != nil {
		log.Fatal(err)
	}
}

func run() error {
	dsn := os.Getenv("DATABASE_URL")
	if dsn == "" {
		return fmt.Errorf("DATABASE_URL is required")
	}
	store, err := storage.New(context.Background(), dsn)
	if err != nil {
		return fmt.Errorf("connect storage: %w", err)
	}
	defer store.Close()

	execClient, err := executor.NewClient(context.Background(), dsn)
	if err != nil {
		return err
	}
	defer execClient.Close()

	interval := defaultIntervalMinutes
	if raw := os.Getenv("SNAPSHOT_INTERVAL_MINUTES"); raw != "" {
		if n, err := strconv.Atoi(raw); err == nil && n > 0 {
			interval = n
		}
	}

	ctx, cancel := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer cancel()

	log.Printf("tracker: snapshotting every %d minutes", interval)
	runLoop(ctx, store, execClient, time.Duration(interval)*time.Minute)
	return nil
}

// executorClient is the subset of *executor.BinanceExecutor this package
// calls — lets tests substitute a fake instead of a real Binance
// connection.
type executorClient interface {
	FetchPortfolio(ctx context.Context) (cash float64, positions map[string]float64, err error)
}

// priceStore is the subset of *storage.Store this package calls — lets
// tests substitute a fake instead of a real database.
type priceStore interface {
	LatestPrice(ctx context.Context, exchange, symbol, timeframe string) (price float64, found bool, err error)
	SaveSnapshot(ctx context.Context, s storage.Snapshot) error
}

// runLoop snapshots once immediately, then again on every tick, until
// ctx is done. Same immediate-then-ticker shape as
// market-data/internal/scheduler.pollFundingAndOI.
func runLoop(ctx context.Context, store priceStore, execClient executorClient, interval time.Duration) {
	ticker := time.NewTicker(interval)
	defer ticker.Stop()

	snapshotOnce(ctx, store, execClient)
	for {
		select {
		case <-ticker.C:
			snapshotOnce(ctx, store, execClient)
		case <-ctx.Done():
			return
		}
	}
}

// snapshotOnce fetches the real portfolio, prices every held position
// via the latest 1m candle, and persists one equity_snapshots row. Any
// failure (portfolio fetch, a missing price) skips this cycle entirely
// — logged, never a partial or inaccurate snapshot. The next cycle
// starts over from scratch.
func snapshotOnce(ctx context.Context, store priceStore, execClient executorClient) {
	cash, positions, err := execClient.FetchPortfolio(ctx)
	if err != nil {
		log.Printf("tracker: fetch portfolio: %v", err)
		return
	}

	positionsValue := 0.0
	for asset, qty := range positions {
		price, found, err := store.LatestPrice(ctx, risk.ReferenceExchange, asset, priceTimeframe)
		if err != nil {
			log.Printf("tracker: price for %s: %v", asset, err)
			return
		}
		if !found {
			log.Printf("tracker: no price data for %s, skipping this cycle", asset)
			return
		}
		positionsValue += qty * price
	}

	snapshot := storage.Snapshot{
		Timestamp:      time.Now().UTC(),
		Cash:           cash,
		PositionsValue: positionsValue,
		TotalEquity:    cash + positionsValue,
	}
	if err := store.SaveSnapshot(ctx, snapshot); err != nil {
		log.Printf("tracker: save snapshot: %v", err)
		return
	}
	log.Printf("tracker: snapshot saved — cash=%.2f positions_value=%.2f total_equity=%.2f", snapshot.Cash, snapshot.PositionsValue, snapshot.TotalEquity)
}
```

```go
// web-api/internal/storage/equity.go
package storage

import "context"

// RecentEquitySnapshots reads real portfolio-value snapshots persisted
// by the tracking module's equity_snapshots table — reuses EquityPoint
// (already defined for backtest_equity_curve) since both represent the
// same (ts, cash, positions_value, total_equity) shape. Returns the
// `limit` most recent snapshots in chronological (oldest-first) order,
// ready for direct charting without any caller-side reordering — same
// convention BacktestDetail's equity curve already uses.
func (s *Store) RecentEquitySnapshots(ctx context.Context, limit int) ([]EquityPoint, error) {
	rows, err := s.pool.Query(ctx, `
		SELECT ts, cash, positions_value, total_equity FROM (
			SELECT ts, cash, positions_value, total_equity
			FROM equity_snapshots
			ORDER BY ts DESC
			LIMIT $1
		) recent
		ORDER BY ts ASC
	`, limit)
	if err != nil {
		return nil, err
	}
	defer rows.Close()

	snapshots := []EquityPoint{}
	for rows.Next() {
		var e EquityPoint
		if err := rows.Scan(&e.Timestamp, &e.Cash, &e.PositionsValue, &e.TotalEquity); err != nil {
			return nil, err
		}
		snapshots = append(snapshots, e)
	}
	return snapshots, rows.Err()
}
```
